# 2026-08-12 Mac導入と正式配布対応

## 目的

- このMacへ現在の公開最新版KoeTsumugiを導入する。
- インストール済みの旧Handy_mをアンインストールし、既存の設定・履歴・録音・モデルは保持する。

## 実施

- GitHub APIで公開最新版が`KoeTsumugi v1.0.4`、tag `handy-m-v1.0.4`、release commit `d6eeacd0c454ab56c686fe2a8d7b5c3f63d2bd45`であることを確認した。
- 公開releaseはWindows x64 NSISのみでmacOS binaryを提供していないため、公式repositoryの`shotaro/custom`をcommit `a2fc387ade11889cf331baddef15459f9483d826`へfast-forwardした。release tag以降は公開結果とローカルbranch整理のdocs commitだけ。
- `bun install --frozen-lockfile`、format、lint、frontend build、23言語のtranslation checkを実行した。
- Rust stable 1.94.1とBun 1.3.10で`bun run tauri build --bundles app`を実行し、Apple Silicon向け`KoeTsumugi.app`を生成した。
- 実行中の旧アプリがないことを確認して`/Applications/Handy_m.app`を`~/.Trash/Handy_m.app`へ移動した。`~/Library/Application Support/com.shotaro.handym`は削除していない。
- 生成したapp bundleを`/Applications/KoeTsumugi.app`へinstallし、`--start-hidden`で起動した。

## 注意点

- macOS公式配布はなく、今回のinstallは公開sourceからのローカルbuild。`tauri-nspanel 2.1.0`の再配布許諾が未確定のため、macOS binaryの公開可否とは分けて扱う。
