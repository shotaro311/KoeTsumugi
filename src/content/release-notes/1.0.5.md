## macOS正式配布を開始

Apple Silicon搭載Mac向けに、Developer ID署名とApple公証を通したDMGを
GitHub Releasesから配布できるようになりました。初回起動時は、音声入力に必要な
マイクとアクセシビリティの権限をmacOSの案内に沿って許可してください。

## Macでも既存データを保持

これまでローカルビルド版を使っていた場合も、設定、履歴、録音、ダウンロード済み
モデルは従来の保存先を引き継ぎます。アプリ内の自動更新もmacOSに対応しました。

## 配布物の安全確認を強化

macOSを含む依存ライセンス台帳を更新し、署名、公証チケット、Gatekeeper、
更新署名をRelease前に自動確認するようにしました。
